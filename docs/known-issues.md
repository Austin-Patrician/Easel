# 已知问题

本页记录目前已知、且与 Easel 使用相关的问题，以及推荐的规避方式。遇到未列出的问题，欢迎提交 [Issue](https://github.com/ZJU-REAL/Easel/issues)。

---

## 平台登录与账号校验

- **扫码后一直等待**：手机扫码不等于登录完成，还需要在 App 中确认。只有平台接口返回当前账号，或页面明确显示登录后界面，才会标记成功。
- **头像或昵称不属于当前账号**：账号卡片只读取当前账号区域或官方账号接口，避免取到管理员头像或信息流中的其它用户。
- **成功后校验返回空白身份**：登录浏览器需要先保存并释放登录目录，再执行校验。网络异常或页面空白会保留上次已验证的身份，不会误报退出登录。
- **刷新二维码或网络中断**：重新点击登录会先退出旧扫码进程，再生成新二维码。频繁重试仍失败时，请检查服务器到平台域名的网络连通性。
- **小红书提示 IP 风险**：平台可能对数据中心网络或自动化操作触发风控。先确认目标网站在可信网络可访问；必要时在桌面环境使用 `xhs_publish.py login --headed --no-proxy` 查看平台原始提示。不要公开或互相传递 Cookie、浏览器登录目录。
- **公众号后台未登录**：公众号发布使用独立的扫码会话。请先在「账号」页完成公众号登录，再执行自动发布。

## 模型与对话

- **还没有可用模型**：运行 `pi` 并执行 `/login`，或在 `.env` 配置 `EASEL_DIRECT_API_KEY`、`EASEL_DIRECT_API_BASE_URL`、`EASEL_DIRECT_API_MODEL`。
- **第三方 OpenAI-compatible 端点超时**：确认 Base URL 包含 `/v1`，模型支持流式输出和工具调用；本地服务不要经过外部 HTTP 代理。
- **对话中断后继续**：Web 会从 `outputs/_pi/jobs/<turnId>.jsonl` 重放已产生的事件；刷新页面不会丢失已完成的内容。
- **工具被拒绝**：检查「设置 → pi」中的 sandbox 权限。`read-only` 会阻止写文件和执行命令；需要执行项目脚本时切换到 `workspace-write`。
- **旧会话无法继续**：旧版非 pi 会话不会迁移；请新建 pi 会话。

## 媒体与发布

- **媒体脚本找不到 Python 依赖**：运行 `bash setup.sh`，或手动执行 `.venv/bin/python -m pip install -e .`。
- **发布超时**：视频处理、上传和平台审核都可能超过单次请求预算。先在内容库确认素材可播放、体积合理，再重试。
- **人工发布包如何使用**：解压 ZIP，在平台官方发布页粘贴标题/正文、上传 `media/` 中的素材，检查预览后亲自发布。导出不等于上传或发布。
- **自动发布的风险**：自动发布会真实操作账号，平台可能要求短信验证或触发风控。建议先用 `EASEL_PUBLISH_MODE=manual` 审核内容。

## 反馈时请提供

- 操作系统、Node.js 与 Python 版本；
- `easel doctor` 输出；
- 脱敏后的 `outputs/_pi/jobs/*.jsonl` 或相关平台日志最后几十行；
- 复现步骤和预期结果。

请删除 Cookie、API Key、二维码令牌、账号身份和完整登录跳转地址后再提交。
